# Viewport Works

Premium technical production website for Viewport Works LLC.

## Production partner section

The `/event-planners` experience includes a static 3×3 Selected Production Partners logo grid in the partnership section. Partner logos are stored as local SVG assets under `public/partner-logos/` and share a common visual bounding box so differing source aspect ratios render at a consistent optical scale.

Current display order:

1. Soundhouse AV Rentals
2. Shadowbox Design Management
3. Long Island Video / LIVE
4. Hart to Hart Entertainment
5. Boom Event Source
6. NY Talent Group
7. DJUSA
8. DJs Unlimited / DJU Events
9. InHouse Design

The partner assets are local SVG treatments intended for consistent site presentation. Where an official downloadable vector master was not publicly available, the local asset is a clean vector treatment based on the company's current public branding rather than an unverified third-party logo download.
